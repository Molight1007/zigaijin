# 04 配置对齐：跟谁比、对齐哪些项

> **一句话**：5 个对手，5 张对齐卡。**每张卡里，我们和它只差一个 K——其余全部用它的原值。**

---

## 一、对齐总原则

```
拿它的流程 → 保留它所有参数 → 只动它的「接受判定」那一处 → K 进准则
```

**不重写流程，只插一个判定。** 这样每张卡的变量都只有一个。

---

## 二、每张卡都必须一致的 10 项（用它的原值，不许动）

| # | 对齐项 | 说明 |
|---|---|---|
| 1 | **初始 harness（H0）** | 用它原本那个，不换 |
| 2 | **演化轮数** | 它的 T / epoch |
| 3 | **每轮候选数 / 接受数** | 它的 b_min、b_max、接受上限 |
| 4 | **进化数据** | 它的演化集（能拿到的就用它的） |
| 5 | **评测数据集 + 版本** | 它的集与版本，**版本绝不混用** |
| 6 | **每任务 rollout 数** | 它的 n / k |
| 7 | **评测次数** | 它的重复次数 |
| 8 | **指标口径** | 它的 Acc / Pass@k / Pass^k |
| 9 | **统计方法** | 它的 bootstrap 次数与置信水平 |
| 10 | **搜索预算** | 由轮数推出的总候选量 |

## 七、跨论文怎么放进同一张表

底座不同，**绝对分数不可比**，只比相对增益：

$$\Delta S = S_{\text{ours}} - S_{H0,\text{同配置}} \qquad \Delta K = \frac{K_{H0} - K_{\text{ours}}}{K_{H0}}$$

每个对手都换算成"自己相对自己 H0 的涨幅"，才有统一量纲。

**唯一例外**：ModularRSI 那张卡若底座也一致，可直接比绝对分数。

## 八、顺序

| 段 | 做什么 | 判据 |
|---|---|---|
| **S1–S3** | ModularRSI 卡内：复现 H0 → 复现基线 → 加 K | 3 次极差 ≤ δ |
| **S4** | 卡内消融：K 关 / 白名单关 / 单池 / 启发式删 | 每组答一个必问质疑 |
| **T1–T2** | AHE 卡 → ModularRSI 卡交叉验证 | 各自 ΔS 不劣、ΔK < 0 |
| **T3–T4** | RRSI 卡 → RHO 卡（HarnessPro 可复用 RHO） | 同上 |
| **最后** | 统一擂台：H0 / ModularRSI / AHE / 我们（±K） | 出排名表 |

**S1 落不到 47.57 附近就停**，说明实现跑偏，后面全是白跑。

## 只记一件事

**每张卡内部只差一个 K；跨卡之间不需要彼此一样——因为比的是相对增益 ΔS / ΔK，不是绝对分数。**
