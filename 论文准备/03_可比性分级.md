# 03 可比性分级

> **一句话**：11 篇里**只有 1 篇能完全对比**（ModularRSI），1 篇接近（TTHE），6 篇只能半对比，3 篇只能参考。

---

## 一、分级标准（四条硬条件，缺一条就降级）

| 代号 | 条件 | 缺了会怎样 |
|---|---|---|
| C1 | 数据集公开、能下到**同版本** | 题不同，数字不可比 |
| C2 | **同 H0** + 同档底座 | 只能比方向，不能比绝对值 |
| C3 | 协议公开（轮数/候选/k） | 复现不了 |
| C4 | 代码开源可跑 | 只能看论文 |

- **A 完全可比** = 四条全中
- **B 半可比** = C1+C3 中，但 C2 不同
- **C 只能参考** = C1 或 C3 不满足

---

## 二、分级结果

### A 级：完全可比（1 篇）

| 论文 | 为什么 |
|---|---|
| **ModularRSI** | TB2.0 + SWE-V 公开 · **Terminus-2 + Harbor** · **DeepSeek-V4-Flash** · 代码 3,253/3,253 文件全下齐 |

**它是我们唯一的主锚。**

### A− 级：接近（1 篇，只差代码确认）

| 论文 | 差在哪 |
|---|---|
| **TTHE** | 底座同为 deepseek-v4-flash、TB2.1 公开、three-run；**代码仓库未确认**。<br>它的 **TB2.1 67.8 比 ModularRSI 的 52.43 更硬，是真靶子** |

### B 级：半可比（6 篇）

| 论文 | 差在哪 | 我们能比哪一格 |
|---|---|---|
| RRSI | 底座 Opus 4.8；三个基准拿不到 | **TB2.1 同 H0**，比增益与 CI |
| HarnessPro | H0 是 Codex/Claude Code，底座 GPT-5.5 | TB2 59+10（RHO 协议），比同 S 下 K |
| Meta-Harness | 底座 GPT-OSS，H0 因任务而异 | **文本分类可做到 A**（底座开源） |
| RHO | 底座 GPT-5.5 | 协议最清楚（给了 pinned commit 与 hash 划分），**直接抄它的划分** |
| AHE | **H0 是弱种子**，跟我们完全不同 | 只比"从弱种子到 77.0 的路径" |
| HarnessX | H0 不明 | +44% 来自最弱底座，强底座会小很多 |

### C 级：只能参考（3 篇）

| 论文 | 为什么 |
|---|---|
| **DGM** | 用**分阶段评估**（越有信心测越多题），分母是动态的 |
| **SICA** | SWE-V **自选 50 题子集**，H0 是自建 agent |
| **HarnessDev** | 不是方法对手，是**评测协议与反面证据** |

## 三、这张表决定的三件事

### 1. 主实验只有一条路

**Terminus-2 + DeepSeek** —— 只有这个组合同时满足 A 级与 A− 级的可比条件。

靶子：ModularRSI 52.43（TB2.0）、TTHE 67.8（TB2.1）。

### 2. 统计要做到 RRSI 的水平

它有 bootstrap 10,000 次 + **两次独立演化**。我们至少要对齐，否则是短板。

> 我此前说"RRSI 没有误差棒"是错的——它表 6、表 7 都有。

### 3. 三个基准拿不到，必须写进论文

| 拿得到 | 拿不到 |

| TB2 / SWE-V / SWE-Pro / JobBench / GDPval / APEX | **Harvey LAB、EngDesign、Frontier-Eng** |
