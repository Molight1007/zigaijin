### 1.2 `domain/evaluate.py` 里三个函数没人用，而 `gate.py` 有同一份

**改前**（`domain/evaluate.py`，12 行）
```python
def delta_s(cand: Score, base: Score) -> float:
    return cand.S - base.S

def delta_c(cand: Score, base: Score) -> float:
    if base.C == 0: return cand.C
    return (cand.C - base.C) / base.C        # ← 与下面 gate._rel 完全一样

def delta_k(cand_k: float, base_k: float) -> float:
    if base_k == 0: return cand_k
    return (cand_k - base_k) / base_k        # ← 与 gate._rel 完全一样
```

**另一处**（`domain/gate.py:142`，实际在用）
```python
def _rel(new: float, old: float) -> float:

```

**判定**：三个函数全项目零引用，而 `gate._rel` 是同一逻辑且在用。**已删这 12 行。**

### 2.2 三个地方各写了一遍"从 dict 或对象里取字段"

```python
# domain/prune.py:33  _f()
def _f(rec, key, default=None):
    """账本记录可能是 dataclass 也可能是从 jsonl 读回来的 dict。"""
    if isinstance(rec, dict): return rec.get(key, default)
    return getattr(rec, key, default)

# domain/simplify_guard.py:?  _f()
def _f(c, key, default=None):
    """候选可能是 dataclass 也可能是 dict。"""
    if isinstance(c, dict): return c.get(key, default)
    return getattr(c, key, default)      # ← 和上面除了参数名，完全一样

# domain/llm_metrics.py:?  _get()
def _get(obj, key, default=None):
    if obj is None: return default        # ← 多这一行
    if isinstance(obj, dict): return obj.get(key, default)
    return getattr(obj, key, default)
```

**背景**：这三处都是为了"同一个对象可能是 dataclass 也可能是 dict"——因为账本/候选既可能来自内存对象，也可能来自读回的 jsonl。

| 方案 | 做法 | 省多少 |
|---|---|---|
| A 抽成一个 | 放 `domain/` 下一个公共位置，三处 import | 15 行 → 6 行 + 3 import，**净省 9 行** |
| **B 不动** | — | 0 |

**比 2.1 更值得做**：三份是**真字节级重复**，没有额外参数。但省 9 行。
