## §3 实际改了什么（两处，一次一处）

### S1｜①删：`report._load_ledger` 与 `dataset.load` 完全同构

```python
# report.py 原版（9 行）
def _load_ledger(path):
    p = Path(path)
    if not p.exists(): return []
    rows = []
    for line in p.read_text(...).splitlines():
        if line.strip(): rows.append(json.loads(line))
    return rows
```
```python
# dataset.load（3 行，早就有）
def load(path):
    p = Path(path)
    if not p.exists(): return []
    return [json.loads(l) for l in p.read_text(...).splitlines() if l.strip()]
```

**等价条件**：对任意路径，两函数返回 `list[dict]` 且元素逐个相等
（都查 `exists()`、都按行 `splitlines`、都跳过空行、都 `json.loads`）。

**差分测试**：7 例 —— 不存在的路径 / 空文件 / 只有空行 / 正常 2 条 /
带空行的混合 / 真实 `feedbacks.jsonl`(22 条) / 真实 `experiments.jsonl`(1 条)。
**7/7 一致。**

### S2｜②替换 R9：`for: lines.append(...)` → `lines += [推导式]`（3 处）

`report.to_markdown` 里三处（`kpi.missing` 列表、`drift.alerts`、`warnings`）。

**等价条件**：`lines` 是 list 且可 `+=`（`__iadd__` 原地，与 `append` 同）；
循环体只有一条纯 append；无 `break`/`continue`；不修改 `lines` 以外的东西；
被遍历对象在循环中不变。

**差分测试**：64 例 —— `kpi.status`(ok/insufficient) × `missing`(空/非空) ×
`alerts`(空/非空) × `warnings`(空/非空) × `top_units`(空/非空) × `drift.status`(ok/alert)
全组合，比 `to_markdown()` 的完整输出。**64/64 逐字节一致。**

### 放弃的一处（诚实记录）

`report.py:177` 的分支分布循环**没改**：改成推导式后因为太长必须换行，
**行数不变、AST 节点可能反升**。按 N6「用行数下降当简化成功」的反例，不改。
