## 三条纪律

1. **先定表格再采数据**。表格里没有的列，采了也是废数据。
2. **措辞不超证据**。「没测出影响」≠「没用」；「我们更低」必须带 n 和区间。
3. **任何数字都要能追到一条命令**。

## 两条防复发规则

- 「只有 / 全都 / 唯一 / 没有一篇」开头的句子，必须附穷举清单。
- 说「某方法缺少 X」之前，必须搜过正文 + 全部附录。
