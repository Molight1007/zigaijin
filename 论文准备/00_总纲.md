# 00 总纲

> **一句话**：在通过率不降的前提下，把 harness 的**源码长度 K** 当作第三道关卡，
> 并用「删掉再跑一遍」证明 K 的下降是真删掉的，不是没测出来的。

---

## 一、我们要主张什么

别人都在做「更强的 harness」，我们做**同样强但更短**的 harness。

| 维度 | 别人 | 我们 |
|---|---|---|
| 比什么 | 通过率 S、成本 C | S、C、**长度 K** |
| 复杂度怎么处理 | 用 token 成本代理，或只定性讨论 | **可复算的 K，能单独否决** |
| 压缩依据 | 提案被拒/接受（判断） | **删了真跑**（实测） |
| 防过拟合 | critic 拦提案 | critic + **量外池隔离** |

---

## 二、跟谁比：三层，别混

| 层次 | 回答什么 | 落在论文哪 |
|---|---|---|
| **方法层** | 跟谁比分数 | 主结果表 |
| **口径层** | 怎么保证公平 | 实验设置 |
| **主张层** | 我们占哪一格 | 引言 + 贡献 |

最常见的失误：只在方法层比分数，被问「你跟 RRSI 的区别不就是少涨 0.5 分」。

---

## 三、比什么：三档，从便宜到贵

| 档 | 对手 | 目的 |
|---|---|---|
| **必比** | RRSI、ModularRSI、AHE、H0 | 论文的骨架 |
| **应比** | Meta-Harness、HarnessPro、RHO | 覆盖不同流派 |
| **只引** | TTHE、HarnessX、DGM、SICA | 脉络与旁支 |

|---|---|---|

## 五、采哪些数据

十类字段，缺一类就有表格填不出来：

1. 能力 **S**（每任务每 trial 二值；Pass@k 与 Pass^k 都记）
2. 成本 **C**（token / 美元 / 步数）
3. 长度 **K**（按组件分：prompt / tools / middleware / memory / subagent / skills）
4. 变化 **ΔK**（增 / 删 / 改三分量，**改写不算删**）
5. **删测证据**（删前 S / 删后 S / 判定三态）
6. **泄漏筛查**（含拦截时点，必须在评测之前）
7. **地板与噪声**（S\* 与 δ，δ 要实测）
8. **池标记**（演化池 / 量外池）
9. **谱系**（候选 → 父代 → 裁决）
10. **失败签名**（同因率）

## 六、现在缺什么

| 缺口 | 严重度 |
|---|---|
| K 只覆盖 skill 文本，工具 / middleware / 内存都没算 | 高 |
| 没有组件粒度的账本（`unit_id` 恒为 `skill::body`） | 高 |
| 没有量外池隔离 | 中 |
| 没有多次独立演化与 CI | 中 |

---

## 只记一件事

**K 降了不算成果，「K 降了且删测证明没掉分」才算。**
